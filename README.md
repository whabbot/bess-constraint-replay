# bess-constraint-replay

This repo will replay GB battery constraint windows from public Elexon and NESO data and estimate repetitive re-trading cost.

The design record is in [docs/decisions.md](docs/decisions.md). The type contract is in [docs/types.md](docs/types.md). The implementation sequence is in [docs/plan.md](docs/plan.md). The throwaway data spike is in [scratch/spike](scratch/spike).

Figures the public data cannot support are estimates. This project does not give trading or investment advice.
